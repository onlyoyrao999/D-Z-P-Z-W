## 📖 一、干什么用的？（核心价值与功能）

在日常使用 AI 生成动作戏、仙侠打斗或武侠动作时，普遍面临三大痛点：
1. **画面漂移无重力**：人物缺乏地面接触感，悬空乱飘，动作没有受力支点；
2. **运镜机械像CG游戏**：镜头死锁无物理微晃，缺乏好莱坞电影工业的真实惯性；
3. **招式空洞无冲击力**：缺少顿挫感（Hit Stop）、闪白冲击帧（Flash）与环境物理交互反馈。

### 本技能的四大核心杀手锏：

1. **全局空间站位记忆点法则 (Global Spatial Anchoring)**

   - **环境地貌参照系**：将人物与固定刚体（古刹中轴线、环形石阵圆心、香炉基座）死锁绑定，确保前后分镜一致性。
   - **肢体与兵刃几何构图**：规范对角线、等腰三角等强识别剪影。
   - **场域空间断层**：周身半径两米真空压降与外围碎石横飞的动静区隔。

## 🛠️ 二、安装方法 (支持豆包 / Codex / GPTs / Claude)

### 方法 1：安装到 豆包 (Doubao) 智能体

1. 打开 [豆包官网](https://www.doubao.com/) 或豆包 App，进入 **“智能体中心”** -> 点击 **“创建智能体”**。
2. 设定智能体基本信息：
   - **智能体名称**：高燃武打提示词扩写专家
   - **简介**：好莱坞工业级动作武打分镜与提示词生成器
3. 在 **“人设与回复逻辑” (System Prompt)** 输入框中，直接粘贴本项目导出的 Markdown Skill 全文（可通过网页端右上角 **“安装到豆包/Codex”** 一键复制）。
4. 在“高级配置”中选择长文本与高推理能力模型。
5. 点击 **“保存发布”**，即可开始对话使用！

---

### 方法 2：安装到 OpenAI Codex / Dify / FastGPT

1. 在工作流或 Agent 编排界面中，新增一个 **LLM 节点** 或 **System Role** 设定。
2. 将 Skill 完整提示词粘贴到 `System Instructions` 中。
3. 设定输出格式为纯 Markdown，温度推荐设为 `0.7`。
4. 输入变量设置为 `{{user_draft}}`（即用户的打斗草稿）。

---

### 方法 3：安装到 ChatGPT (Custom GPTs) / Claude Projects

1. **ChatGPT**:
   - 点击 **Explore GPTs** -> **Create a GPT** -> 进入 **Configure** 标签页。
   - 将完整 Skill 文本粘贴到 **Instructions** 输入框。
   - 取消勾选 Code Interpreter（不需要），保持纯文本高质量生成。
2. **Claude Projects**:
   - 在 Claude 中新建一个 Project，在 **Project Knowledge / Custom Instructions** 中填入本 Skill 文本。

---

### 方法 4：在本网页应用中直接使用

1. 打开应用主界面：
   - 在输入框中输入任何简短的动作草稿（例如：`两人在雨夜古刹拔刀博杀，触发终极奥义·傲雪凌霜`）。
   - 可在下方点击 **“32条核心动作库”** 或 **“终极奥义库 (111+)”** 快速挑选并绑定招式。
   - 在 **空间站位记忆点面板** 选用预设（支持高度锚点、环境坐标、几何构图、场域断层），在 **摄影机控制面板** 调节电影机位（镜头焦段、跟踪链路、冲击要素）与调色盘。
2. 点击 **“一键扩写生成 · 好莱坞电影级提示词”**。
3. 系统将立即输出规范的 Markdown 代码块，支持一键复制英文 Prompt 喂给 Midjourney / Kling / Sora / Runway！

## 📋 三、输入与输出示例

### 用户输入草稿示例：
```text
白衣刀客站在竹林深处，单手反握长刀，蓄力拔刀斩向迎面冲来的刺客，触发终极奥义·八音裂魂。
```

### 交付输出结构：
1. **【第一部分：分镜动作细化（剧本扩写与色彩运镜规划）】**
   - 镜头一：起手式 · 空间站位锁定（垂直高度、环境坐标、构图剪影、场域断层）
   - 镜头二：核心动作交锋（动作发力、摄影机高速追踪甩镜、冲击四要素）
   - 镜头三：终极奥义调用（严格剔除运镜与面部神态，纯粹空间站位 + 起手式 + 蓄力中 + 口型喊名 + 轰然出招）
2. **【第二部分：AI视频/生图通用Prompt清单】**
   - 英文通用提示词 (Positive Prompt)
   - 中文通用提示词 (Positive Prompt)
   - 电影级通用负面词 (Negative Prompt)
