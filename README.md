## 📖 一、干什么用的？（核心价值与功能）

在日常使用 AI 生成动作戏、仙侠打斗或武侠动作时，普遍面临四大痛点：
1. **画面漂移无重力**：人物缺乏地面接触感，悬空乱飘，动作没有受力支点；
2. **运镜机械像CG游戏**：镜头死锁无物理微晃，缺乏好莱坞电影工业的真实惯性与甩镜转场；
3. **招式空洞无冲击力**：缺少顿挫感（Hit Stop）、闪白冲击帧（Flash）与环境物理交互反馈；
4. **单镜头难以成片**：缺乏影视级多镜头能量阶梯（Energy Ladder 1→5→2）、音效卡点与工业级剪辑时间线。

### 本技能的五大核心杀手锏：

## 🛠️ 二、安装方法 (支持豆包 / Codex / GPTs / Claude)

### 方法 1：安装到 豆包 (Doubao) 智能体
1. 打开 [豆包官网](https://www.doubao.com/) 或豆包 App，进入 **“智能体中心”** -> 点击 **“创建智能体”**。
2. 设定智能体基本信息：
   - **智能体名称**：`顶级动作onlyno999`
   - **作者**：`onlyno999`
   - **简介**：顶级动作导演与好莱坞工业级高燃武打提示词扩写专家
3. 在 **“人设与回复逻辑” (System Prompt)** 输入框中，直接粘贴本项目导出的 Markdown Skill 全文（可通过网页端右上角 **“安装到豆包/Codex”** 一键复制）。
4. 在“高级配置”中选择长文本与高推理能力模型，点击 **“保存发布”** 即可使用。

### 方法 2：安装到 OpenAI Codex / Dify / FastGPT
1. 在工作流或 Agent 编排界面中，新增一个 **LLM 节点** 或 **System Role** 设定。
2. 将 Skill 完整提示词粘贴到 `System Instructions` 中。
3. 设定输出格式为纯 Markdown，温度推荐设为 `0.7`。

### 方法 3：安装到 ChatGPT (Custom GPTs) / Claude Projects
1. **ChatGPT**: 在 **Configure** 标签页中的 **Instructions** 输入框粘贴本 Skill 文本。
2. **Claude**: 在 Project 的 **Project Knowledge / Custom Instructions** 中填入本 Skill 文本。

### 方法 4：在本网页应用中直接使用
1. 打开应用主界面，在输入框中输入动作草稿（如：`两人在雨夜古刹拔刀博杀，触发终极奥义·傲雪凌霜`）。
2. 可切换 **Shotcraft 5-Shot 动作工坊序列** 或 **单镜头特写爆发** 模式。
3. 点击 **“一键扩写生成 · Video-Shotcraft 电影级动作交付包”**。
4. 可在右侧分别查看：**分镜工坊卡片**、**Markdown 规范文本**、**AI Prompt 提纯**、**Remotion JSON** 与 **剪映草稿**！
